Sign in yourself in the browser that opens. Go to Admin Settings → Organizations, then click Save signed-in session here. Your password is never sent to the model.

Advanced login setup

Configure deterministic login steps and an explicit logged-in ready locator. Values use credential references username/password, never literals. MFA/CAPTCHA becomes AuthRequired.

All settings / source contracts

Optional contracts map an exact source hash to actions and atomic criteria. Natural-language proposals alone remain NeedsReview, even when their mechanical checks pass.
